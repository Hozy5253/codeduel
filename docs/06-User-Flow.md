   User Opens Website
   │
   ▼
   Clicks "Sign Up"
   │
   ▼
   Enters Name, Email, Username, Password
   │
   ▼
   System Validates Details
   │
   ▼
   Email Verification Sent
   │
   ▼
   User Verifies Email
   │
   ▼
   Account Created

   ▼
   Redirect to Dashboard
